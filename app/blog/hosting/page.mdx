# Domain Hosting with Godaddy & Azure static storage
<br/>
A easy and cheap way to host a simple static website is to use an azure storage account.

## Prerequisites
- Azure Subscription
- GitHub repo with code
- Service Principal
- Azure Storage Account WITH static website enabled

### Service Principal
A Service Principal acts as an identity for GitHub Actions. Instead of storing client secrets, we will use OIDC authentication, which avoids managing credentials manually.

### Configure Secrets in GitHub Actions

Once the Service Principal is created, you need to store IDs so GitHub can authenticate via OIDC:

- Client ID - identifies your Service Principal
- Tenant ID - identifies your Azure AD tenant
- Subscription ID - identifies which subscription to operate in

These values are stored in GitHub Actions secrets, not as passwords, but simply as identifiers.

## Create static website in Azure Storage (Terraform)
Defer to [Simple Terraform state storage in Azure](/blog/tfstate)

add a new resource to the environment:

### strg.tf
```hcl:strg.tf
resource "azurerm_storage_account" "storageAccount" {
  name                     = local.strg_name
  resource_group_name      = azurerm_resource_group.rg.name
  location                 = azurerm_resource_group.rg.location
  account_tier             = "Standard"
  account_replication_type = "GRS"
}

resource "azurerm_storage_account_static_website" "website" {
  storage_account_id = azurerm_storage_account.storageAccount.id
  error_404_document = "custom_not_found.html"
  index_document     = "custom_index.html"
}
```

## Deploy static website with GitHub actions workflow
Build & Deploy the react app with GitHub actions workflow

```yaml:deploy.yaml
name: Deploy React App to Azure Storage

on:
  push:
    branches:
      - main # Trigger on pushes to the main branch

permissions:
  id-token: write
  contents: read

env:
    STORAGE_ACCOUNT: fozzstrgtest # Hardcoded in this example to comply with manual & terraform storage creation

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Set up Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20.9.0' # Use your desired Node.js version

      - name: Install dependencies and build
        run: |
          npm install
          npm run build # This command generates the static files in the 'build' directory (default for Create React App)

      - name: Azure Login
        uses: azure/login@v1
        with:
          client-id: ${{ secrets.AZURE_CLIENT_ID }}
          tenant-id: ${{ secrets.AZURE_TENANT_ID }}
          subscription-id: ${{ secrets.AZURE_SUBSCRIPTION_ID }}

        - name: Upload to Azure Blob Storage
          uses: azure/CLI@v1
          with:
            inlineScript: |
              az storage blob delete-batch --account-name $STORAGE_ACCOUNT --source '$web' --pattern "*"
              az storage blob upload-batch --account-name $STORAGE_ACCOUNT --source out --destination '$web'
```
