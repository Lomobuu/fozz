# Host a Static Website in Azure using Terraform, OIDC & GitHub Actions

This guide shows how to fully automate static website hosting in Azure using:

- Terraform
- Azure Storage (Static Website)
- Azure Front Door
- GitHub Actions
- OIDC authentication (no client secrets)

This is a production-ready, GitOps-style deployment.

# Architecture Overview

GitHub Push  
→ GitHub Actions  
→ OIDC Authentication  
→ Terraform  
→ Azure Storage (Static Website)  
→ Azure Front Door  
→ Custom Domain  

No local execution.  
No stored credentials.  
State stored remotely in Azure.

# Step 1 — Storage Account with Static Website

Add the following to your Terraform configuration.

## strg.tf

```hcl:title=strg.tf
resource "azurerm_storage_account" "storage" {
  name                     = local.storage_name
  resource_group_name      = azurerm_resource_group.rg.name
  location                 = azurerm_resource_group.rg.location
  account_tier             = "Standard"
  account_replication_type = "GRS"
}

resource "azurerm_storage_account_static_website" "static" {
  storage_account_id = azurerm_storage_account.storage.id
  index_document     = "index.html"
  error_404_document = "404.html"
}
```
After deployment, Azure automatically creates the $web container.

This container will host your static files.

Step 2 — Azure Front Door

- Azure Front Door provides:
- Global routing
- HTTPS
- Custom domain support
- Edge acceleration

Custom domain is added manually later

## frontdoor.tf

```hcl:title=strg.tf
resource "azurerm_cdn_frontdoor_profile" "frontdoor" {
  name                = local.frontdoor_name
  resource_group_name = azurerm_resource_group.rg.name
  sku_name            = "Standard_AzureFrontDoor"
}
```

You will also need:

- Endpoint
- Origin group
- Origin (pointing to storage static website endpoint)
- Route mapping frontend to origin
- Front Door becomes the public entry point for your site.

Step 3 — GitHub Actions Deployment Workflow

This workflow:
- Authenticates using OIDC
- Builds your static app
- Runs Terraform
- Uploads static content to $web

## deploy.yaml

```yaml:title=deploy.yaml
name: Deploy Static Website

on:
  push:
    branches:
      - main

permissions:
  id-token: write
  contents: read

env:
  ARM_CLIENT_ID: ${{ secrets.AZURE_CLIENT_ID }}
  ARM_SUBSCRIPTION_ID: ${{ secrets.AZURE_SUBSCRIPTION_ID }}
  ARM_TENANT_ID: ${{ secrets.AZURE_TENANT_ID }}

jobs:
  deploy:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: "20"

      - name: Install & Build
        run: |
          npm install
          npm run build

      - name: Setup Terraform
        uses: hashicorp/setup-terraform@v1

      - name: Terraform Init
        run: terraform init -backend-config="use_oidc=true"

      - name: Terraform Apply
        run: terraform apply -auto-approve

      - name: Azure Login (OIDC)
        uses: azure/login@v1
        with:
          client-id: ${{ secrets.AZURE_CLIENT_ID }}
          tenant-id: ${{ secrets.AZURE_TENANT_ID }}
          subscription-id: ${{ secrets.AZURE_SUBSCRIPTION_ID }}

      - name: Upload Static Files
        uses: azure/CLI@v1
        with:
          inlineScript: |
            az storage blob upload-batch \
              --account-name <your-storage-account> \
              --source out \
              --destination '$web'
```
