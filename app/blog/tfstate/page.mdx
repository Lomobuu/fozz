# Minimal Terraform Configuration

Below is a simple Terraform setup using the AzureRM provider and OIDC authentication.

## main.tf

```hcl:title=main.tf
terraform {
  required_providers {
    azurerm = {
      source  = "hashicorp/azurerm"
      version = "~> 4.61.0"
    }
  }
}

provider "azurerm" {
  features {}
  use_oidc = true
}

resource "azurerm_resource_group" "rg" {
  name     = local.rg_name
  location = var.location
}
```
## variables.tf
```hcl:title=variables.tf
variable "location" {
  type    = string
  default = "westeurope"
}
```

## locals.tf
```hcl:title=locals.tf
locals {
  base    = "simpletst"
  rg_name = "${local.base}-rg"
}
```

This keeps the infrastructure example intentionally simple.

# GitHub Actions Workflow

This workflow:
- Authenticates using OIDC
- Initializes Terraform with remote backend
- Validates and formats code
- Runs plan
- Applies automatically on main

## terraform.yaml
```yaml:title=terraform.yaml
name: Terraform Plan & Apply

on:
  push:
    branches:
      - main
    paths:
      - ".github/Terraform/**"
      - ".github/workflows/terraform.yaml"
  workflow_dispatch:

permissions:
  id-token: write
  contents: read

env:
  ARM_CLIENT_ID: ${{ secrets.AZURE_CLIENT_ID }}
  ARM_SUBSCRIPTION_ID: ${{ secrets.AZURE_SUBSCRIPTION_ID }}
  ARM_TENANT_ID: ${{ secrets.AZURE_TENANT_ID }}

  RESOURCE_GROUP: <backend-resource-group>
  STORAGE_ACCOUNT: <backend-storage-account>
  location: westeurope

jobs:
  terraform:
    runs-on: ubuntu-latest

    defaults:
      run:
        working-directory: .github/Terraform
        shell: bash

    steps:
      - name: Checkout
        uses: actions/checkout@v3

      - name: Setup Terraform
        uses: hashicorp/setup-terraform@v1

      - name: Terraform Init
        run: |
          terraform init \
            -backend-config="resource_group_name=$RESOURCE_GROUP" \
            -backend-config="storage_account_name=$STORAGE_ACCOUNT" \
            -backend-config="container_name=tfstate" \
            -backend-config="key=terraform.tfstate" \
            -backend-config="use_oidc=true"

      - name: Terraform Format
        run: terraform fmt -recursive

      - name: Terraform Validate
        run: terraform validate

      - name: Terraform Plan
        run: terraform plan -input=false -var location=$location

      - name: Terraform Apply
        run: terraform apply -auto-approve -input=false -var location=$location
```

## How It Works

1. GitHub requests an OIDC token
2. Azure validates it via federated identity
3. Terraform initializes using the remote backend
4. Plan and apply execute inside the runner
5. State is written to Azure Storage

### This ensures:

- No local state
- No client secrets
- Reproducible deployments
- Fully automated infrastructure changes
