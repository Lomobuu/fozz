## What This Guide Covers

This guide focuses only on the **automatic backend bootstrap process**.

We will:

1. Create a Service Principal in Azure  
2. Configure Federated Credentials (OIDC)  
3. Assign required roles  
4. Store required IDs in GitHub  
5. Use GitHub Actions to create the Terraform backend 

---

## Architecture Overview

The goal is simple:

GitHub Actions → OIDC authentication → Azure → Create Storage Account + Container

No client secrets.  
No stored credentials.  
No manual backend provisioning.

# Phase 2 — Configure Federated Credentials (OIDC)

Instead of using client secrets, we use **OIDC federation**.

This allows GitHub to authenticate securely without storing credentials.

## Step 3 — Add Federated Credential

Inside your Service Principal:

- Navigate to **Certificates & Secrets**
- Select **Federated Credentials**
- Add new credential

Choose:
- Scenario: GitHub Actions
- Organization
- Repository
- Branch (usually main)

# Phase 4 — GitHub Workflow to Create Terraform Backend

This workflow creates:

- Resource Group  
- Storage Account  
- Blob Container  

It runs once to bootstrap the Terraform backend.

---

## backend.yaml

```yaml:title=.github/workflows/backend.yaml
name: BackendStorageCreate

on:
  workflow_dispatch:

permissions:
  id-token: write
  contents: read

env:
  location: "westeurope"
  terraformStorageRG: <resource-group-name>
  terraformStorageAccount: <storage-account-name>
  containerNameBackend: "tfstate"

jobs:
  setup-terraform-backend:
    runs-on: ubuntu-latest

    steps:
      - name: Azure Login
        uses: azure/login@v2
        with:
          client-id: ${{ secrets.AZURE_CLIENT_ID }}
          tenant-id: ${{ secrets.AZURE_TENANT_ID }}
          subscription-id: ${{ secrets.AZURE_SUBSCRIPTION_ID }}

      - name: Create Backend Resources
        uses: azure/cli@v2
        with:
          azcliversion: latest
          inlineScript: |
            az group create \
              --name $terraformStorageRG \
              --location $location

            az storage account create \
              --name $terraformStorageAccount \
              --resource-group $terraformStorageRG \
              --location $location \
              --sku Standard_LRS

            az storage container create \
              --name $containerNameBackend \
              --account-name $terraformStorageAccount
```

# Phase 4 (Different Method) — GitHub Workflow to Create Terraform Backend WITH terraform

Seperate a bootstrap / terraform state configuration folder from the main infrastructure folder
```bash
└── .github/
    └── Terraform/
        ├── Bootstrap/
        │   ├── main.tf
        │   └── variables.tf
        └── Infra/
            ├── main.tf
            ├── variables.tf
            ├── keyvault.tf
            └── database.tf
```

### main.tf

```hcl:title=.github/Terraform/bootstrap/main.tf
terraform {
  required_version = ">= 1.5.0"

  required_providers {
    azurerm = {
      source  = "hashicorp/azurerm"
      version = "~> 4.68.0"
    }
  }
}

provider "azurerm" {
  features {}
}


resource "azurerm_resource_group" "backend" {
  name     = var.resource_group_name
  location = var.location
}

resource "azurerm_storage_account" "backend" {
  name                     = var.storage_account_name
  resource_group_name      = azurerm_resource_group.backend.name
  location                 = azurerm_resource_group.backend.location
  account_tier             = "Standard"
  account_replication_type = "LRS"
  min_tls_version          = "TLS1_2"

  allow_nested_items_to_be_public = false
}

resource "azurerm_storage_container" "backend" {
  name                  = var.container_name
  storage_account_name  = azurerm_storage_account.backend.name
  container_access_type = "private"
}
```

### variables.tf

```hcl:title=.github/Terraform/bootstrap/variables.tf
variable "location" {
  type    = string
  default = "norwayeast"
}

variable "resource_group_name" {
  type = string
}

variable "storage_account_name" {
  type = string
}

variable "container_name" {
  type    = string
  default = "tfstate"
}
```

### backend.yaml

```yaml:title=.github/workflows/backend.yaml
on: workflow_dispatch

name: BackendStorageCreate

permissions:
  id-token: write # Require write permission to Fetch an OIDC token.
  contents: read

env:
  location: "norwayeast"
  terraformStorageRG: <resource-group-name>
  terraformStorageAccount: <storage-account-name>
  containerNameBackend: 'tfstate'
  backendAzureRmKey: 'terraform.tfstate'
  ARM_USE_OIDC: true
  ARM_CLIENT_ID: "${{ secrets.AZURE_CLIENT_ID }}"
  ARM_SUBSCRIPTION_ID: "${{ secrets.AZURE_SUBSCRIPTION_ID }}"
  ARM_TENANT_ID: "${{ secrets.AZURE_TENANT_ID }}"

jobs:

  build-and-deploy:
    runs-on: ubuntu-latest
    steps:

    - uses: actions/checkout@v4

    - uses: hashicorp/setup-terraform@v3

    - name: Terraform Init (local)
      working-directory: .github/Terraform/bootstrap
      run: terraform init

    - name: Terraform Apply (backend infra)
      working-directory: .github/Terraform/bootstrap
      run: |
        terraform apply -auto-approve -var resource_group_name=$terraformStorageRG -var storage_account_name=$terraformStorageAccount

```
