# Requirements & Installation

You will need:

- [Node.js](https://nodejs.org/en)
- Optionally: [nvm](https://www.nvmnode.com/)

Create a new Next.js project:

```
pnpm create next-app@latest my-app --yes
```
Install Tailwind CSS:
```
pnpm install tailwindcss @tailwindcss/postcss postcss
```
And import it in your global stylesheet:
```css:title=global.css
@import "tailwindcss";
```

# Project strucure

This project uses the Next.js [App Router](https://nextjs.org/docs/app/getting-started/project-structure), meaning routing is filesystem-based. Here's the simplified folder layout:
```bash
└── project/
    ├── app/
    │   ├── blog/
    │   │    ├── page.tsx <- Blog Homepage
    │   │    ├── [slug]/
    │   │    │   └── page.tsx <- Single blog render
    │   ├── page.tsx
    │   └── layout.tsx
    ├── content/
    │   └── <slug> 
    │      └── page.mdx <- Article Content
    └── components/
        ├── navbar.tsx
        └── Codeblock.tsx
```

### /App
The app/ folder is the core of routing:

- `app/page.tsx` → renders the homepage (/)
- `app/layout.tsx` → shared layout (navigation, footer, wrappers)

### /App/Blog
The blog system is entirely filesystem-driven:

- app/blog/page.tsx  renders the blog homepage (/blog) showing all posts
- `app/blog/[slug]/page.tsx`  dynamic route for individual blog posts
- The [slug] folder matches the slug of each blog post in content/
  - Example: `content/terraform-backend/page.mdx` →/blog/terraform-backend
  - Example: `content/ephemeral/page.mdx`  /blog/ephemeral

Content for each post lives in `content/<slug>/page.mdx`, which is imported and rendered via Contentlayer

This setup allows you to add a new blog post simply by creating a new folder in content/ — no changes to routing are required.

MDX files act like pages — no extra configuration needed once MDX is set up.

### /components
Contains shared UI components such as a navigation bar & MDX components such as code block and image
### Other files

- `tailwind.config.ts` - Tailwind CSS configuration
- `next.config.ts` - Next.js configuration including MDX setup
- `package.json` - dependencies and scripts
- `mdx.d.ts` - MDX TypeScript support
- `mdx-components.tsx` - overrides and custom components for MDX (links, images, code blocks, etc.)
- `contentlayer.config.ts` – configuration for Contentlayer, defining where your content lives (content/), the structure of your MDX documents, and any computed fields like slugs. It tells Contentlayer how to read, parse, and generate React-ready data from your MDX files.

# MDX


## install mdx dependencies

```
pnpm add @next/mdx @mdx-js/loader @mdx-js/react @types/mdx
```

## Configure next.config.tsx

```tsx:title=next.config.tsx
import createMDX from '@next/mdx'
import type { NextConfig } from 'next'

const nextConfig = {
  pageExtensions: ['js', 'jsx', 'ts', 'tsx', 'md', 'mdx'],
  output: 'export', // Added for Azure static storage support
} satisfies NextConfig

export default createMDX({
  extension: /\.(md|mdx)$/,
})(nextConfig)

```

## Add & Configure mdx-components.tsx 

```tsx:title=mdx-components.tsx
import type { MDXComponents } from 'mdx/types'
 
const components: MDXComponents = {}
 
export function useMDXComponents(): MDXComponents {
  return components
}
```
## Configure contentlayer.config.ts

Keep in mind this contains support for metadata in the mdx file

```tsx:title=contentlayer.config.ts
import { defineDocumentType, makeSource } from "contentlayer/source-files";

export const Post = defineDocumentType(() => ({
  name: "Post",
  filePathPattern: `**/page.mdx`,
  contentType: "mdx",

  fields: {
    title: { type: "string", required: true },
    date: { type: "string", required: true },
    excerpt: { type: "string", required: true },
  },

  computedFields: {
    slug: {
      type: "string",
      resolve: (doc) => doc._raw.flattenedPath.replace("/page", ""),
    },

    url: {
      type: "string",
      resolve: (doc) => `/blog/${doc._raw.flattenedPath.replace("/page", "")}`,
    },
  },
}));

export default makeSource({
  contentDirPath: "content",
  documentTypes: [Post],
});
```

## Create a blog homepage & blog example
Create a new folder under app called /blog and add a page.tsx. This solution links to the name of your blog folder.

### page.tsx

```
import Link from "next/link";
import { allPosts } from "../../.contentlayer/generated"

export default function BlogPage() {
  const posts = allPosts.sort(
    (a, b) => new Date(b.date).getTime() - new Date(a.date).getTime()
  );

  return (
    <div className="space-y-6">
      <h1 className="text-4xl font-bold">Blog</h1>
      <p className="text-gray-600">
        Welcome to the blog section. Here you'll find all published articles.
      </p>

      <ul className="space-y-4">
        {posts.map((post) => (
          <li key={post.slug} className="border p-4 rounded-lg">
            <Link href={`/post/${post.slug}`}>
              <h2 className="text-2xl font-semibold hover:underline">
                {post.title}
              </h2>
            </Link>
            <p className="text-gray-500">{post.description}</p>
          </li>
        ))}
      </ul>
    </div>
  );
}
```
