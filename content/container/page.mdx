## Install .NET backend extentions


### Install Entity Framework

`dotnet add package Microsoft.EntityFrameworkCore` OR use nuget package manager

`dotnet add package Microsoft.EntityFrameworkCore.SQLServer` OR use nuget package manager

`dotnet add package Microsoft.EntityFrameworkCore.Tools` OR use nuget package manager

### OpenAPI

`dotnet add package Microsoft.AspNetCore.OpenAPI` OR use nuget package manager

### Scalar for OpenAPI

`dotnet add package Scalar.AspNetCore` OR use nuget package manager
